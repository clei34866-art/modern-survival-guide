# 现代必备生存指南 (Modern Survival Guide)

围绕**个人生产力与生活掌控感**构建的纯静态学习与行动平台。不制造续航焦虑、不刷假题、不堆砌黑话——把高价值的现代生存常识拆解进每天可收工的精力节律里，把学到的东西落成生活里真正做成的一件事。

## 在线访问

- **GitHub Pages 在线体验**：[https://clei34866-art.github.io/modern-survival-guide/](https://clei34866-art.github.io/modern-survival-guide/)

## 核心结构与功能

1. **「今天」三时段精力调度台 (`#/`)**
   - 按**早间/通勤碎片、整块高精力时段、晚间低精力轻学**三段节律排定固定上限任务，做完即停、绝不追加新题；昨日未完成项自动翻篇不补账。
   - 支持一键切换**「今天有点累 · 保底版」**，低电量日自动豁免高负荷重活，守住最小节律；累计点亮天数断更不清零、不掉级。
2. **七大生存分支与 eudaimonia 技能树 (`#/branches`)**
   - 覆盖 **B1 AI 与软件硬技能**（AI 能力线 L1–L5 逐层过关解锁 + Blender `bpy` 等软件独立分包）、**B2 个人财经与防坑**、**B3 心理学与决策自知**、**B4 身心健康与精力管理**、**B5 沟通表达与职业发展**、**B6 学习方法与信息素养**、**B7 生活实务与应急自保**。
   - 全部正式学习单元基于权威公开来源整理，标注来源机构、抓取日期、复核时效及财经/心理专业求助边界提示，配参数化精确 SVG 图解。
3. **统一 7 步学习单元流水线 (`#/unit/:id`) & 间隔重测中心 (`#/review`)**
   - 每个学习单元均遵循：**生活场景开场 → 先预测（反直觉判断） → 图文导学 → 跨分支知识图谱概念卡 → 编号自测 → 真实行动任务（含费曼一句话检查） → 过关留痕**。
   - 自测错题与「模糊/重来」概念卡自动排入 **1 / 3 / 7 天间隔重测队列**，聚合薄弱概念 TOP 5。
4. **跨分支生活事件包与工具箱 (`#/events`)**
   - 按真实生活事件（如「准备一次重要汇报/展示」「筹备一次省心出行与预算」）跨分支组包联动「今天」调度流，并沉淀可反复打勾复用的核对清单。
5. **真实任务池、生活实验室与简版周复盘 (`#/lab`)**
   - **真实任务池**：录入科研、写作、预算等真实待办，在学习单元行动步一键绑定抵扣。
   - **生活实验室**：按月控制单一生活变量（睡眠、消费冷静期等），记录基线与实测曲线对比，自动汇总进每周生活复盘。
6. **1080P 全屏个人状态墙 (`#/wall`)**
   - 面向桌面横屏常亮的深底高对比六宫格总览（含 B1 专项数字看板二级切换视图），无真实记录时展示 `DEMO` 示例态，产生学习留痕后自动切换为 `LIVE` 实况态；手机端访问时自动降级为单栏清晰视图。

## 数据存储与跨设备迁移说明（无云同步）

- **纯本地浏览器存储**：本项目为纯静态前端单页应用（Preact + TypeScript + Vite），**不包含后端账户系统，也没有自动云同步功能**。
- **IndexedDB 持久化**：所有答题记录、学习用时、过关产出、真实任务池、生活实验及每日清单均保存在当前设备本地浏览器的 `IndexedDB`（数据库名 `modern_survival_guide_v1`）中；清理浏览器站点数据将清空本地记录。
- **跨设备迁移方式**：如需在电脑、平板或手机之间迁移学习数据，请打开站内 **「真实任务与实验室 → 本地留痕与 JSON 备份」**，通过 **「导出 JSON 备份」** 与 **「导入校验 JSON」** 手动完成跨设备备份与恢复。

## 本地运行与构建

环境要求：**Node.js 20+** 与 **npm**。

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务器
npm run dev

# 3. 内容合规校验 + TypeScript 类型检查 + 生产构建
npm run build

# 4. 本地预览生产构建产物
npm run preview

# 5. 运行核心逻辑与全量内容红线冒烟测试
npm run smoke
```

如需构建用于 GitHub Pages 子路径（`/modern-survival-guide/`）的静态产物，可执行：

```bash
npm run build:pages
```

应用全局采用 Hash 路由（`#/...`），在 GitHub Pages 等纯静态托管环境下任意子页面直接刷新均不会触发 404。
